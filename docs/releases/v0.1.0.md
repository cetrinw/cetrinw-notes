# Cetrinw v0.1.0 · macOS 预览版

Cetrinw 的首个 GitHub 预览版本，把本地笔记、产业研究、订阅阅读与英语学习放在一个桌面工作台中。笔记和附件保存在本机，基础使用无需账号或服务器。

## 下载与安装

适用平台：**Apple Silicon Mac（M 系列芯片），macOS 13 或更新版本**。本次未提供 Intel Mac、Windows、Linux 或移动端安装包。

| 文件 | 用途 |
| --- | --- |
| `Cetrinw_0.1.0_aarch64.dmg` | 打开镜像，将 Cetrinw 拖入“应用程序” |
| `Cetrinw_0.1.0_aarch64.app.zip` | 解压后得到同一版本的 `.app` |
| `SHA256SUMS` | 两个安装包的 SHA-256 校验值 |
| `release-info.json` | 构建提交、平台、文件大小、校验值及验证范围 |

将两个安装包和 `SHA256SUMS` 下载到同一目录后，可以运行：

```sh
shasum -a 256 -c SHA256SUMS
```

仅下载其中一个安装包时，可运行 `shasum -a 256 文件名`，与 `SHA256SUMS` 中对应行比较。

安装包使用本机 **ad-hoc 签名**，尚未进行 Apple Developer ID 签名和公证。macOS 可能提示无法验证开发者；确认文件来自本仓库后，可通过系统“隐私与安全性”中的“仍要打开”完成首次启动。

已有用户升级前，请在“设置与数据”中导出完整备份。macOS 默认资料库位于 `~/Library/Application Support/org.cetrinw.notes/`，安装包不包含个人资料库。

## 本版功能

- **笔记**：富文本、任务列表、代码、公式、表格、附件、中文搜索、引用与反向链接、版本历史和删除恢复。
- **研究**：专题、对象、关系、事件、假设与证据；周期阶段、时间轴、指标图表及研究模板。
- **阅读**：RSS / Atom、OPML、订阅发现、文章收藏与转存笔记、正文抓取、阅读进度和系统朗读。
- **英语**：VOA Level 1 52 课和 ELLLO A1 25 课目录；自有音频与字幕导入、逐句循环、时间轴校准、录音和 FSRS 生词复习。
- **本地数据**：SQLite、30,066 条 ECDICT 英汉词典、附件 SHA-256、完整备份与恢复；按需配置个人服务器同步和 WebDAV 备份。

## 已知问题与边界

- **RSS 全文保存问题**：再次刷新可能把已抓取正文替换为摘要，并清除对应译文。重要内容建议先转存为笔记。
- **同步批次上限**：单次同步最多发送 500 条待同步记录，大批导入后可能需要多次同步；界面“同步完成”尚不能证明全部待发记录已排空。
- **离线翻译尚未完成**：ONNX 推理未接通，新译文当前依赖 MyMemory 公共接口；已保存的译文和缓存可离线读取。
- **金融数据边界**：日线为未复权价格，拆股、分红和完整交易日历尚未完整处理。部分数据源需要 API 凭据，外部来源可能失效或限流。
- **同步与备份**：面向个人使用，没有多人实时协作和端到端加密。WebDAV 单份完整备份上限 250 MB，不自动删除远端历史。
- **仍需专项回归**：原生麦克风、系统媒体中断、中文输入法、异常退出恢复和长期运行。
